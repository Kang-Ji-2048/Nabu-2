# Third-party materials

The MIT licence applies to Nabu's software. It does not relicense ticket datasets,
tracker exports, recorded project text, screenshots or other third-party inputs.
Those materials retain their own rights and usage restrictions.

The TAWOS adapter reads the TAWOS dataset; that dataset is not included in the Python
wheel. The existing project documentation describes TAWOS research-use restrictions.
Check the dataset's own terms before importing, distributing or using its records.

The dump reader, extraction helpers and mappings were carried forward from Nabu 1,
as recorded in `docs/agents.md`. Preserve that attribution when redistributing them.
Dependencies, including the optional Anthropic SDK, retain their own licences.

The standalone dashboard, recorded runs, slides and screenshot assets are not
bundled in the Python wheel. The source repository may contain such materials;
the software licence does not grant additional rights to their underlying data.
