Nabu is a delivery-risk review workflow built with Python, SQLite and optional Claude Messages API calls. A historian mines patterns from completed ticket history. A planner routes a new epic to an estimator, dependency hunter and gap finder. Python supplies citations and checkable predictions; the model phrases findings. A critic applies code-enforced citation and viewer-scope rules, with one revision pass, before a writer saves the review. The scorekeeper checks warnings against later outcomes and adjusts pattern weights. Durable checkpoints support pause and resume. Response validation, bounded requests and rollback protect the workflow. The hosted product displays saved project snapshots immediately; live reviews require a connected Python API. It does not use the Agent SDK or Managed Agents.
